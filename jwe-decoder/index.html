NextAuth JWE Decoder

Decrypt NextAuth v4 session tokens in your browser.

Decoding happens on this device. You can disconnect from the internet after the page loads.

Input

Paste your NextAuth secret and the JWE from the session cookie.

Output

Decoded JWT payload

Decoded JSON will appear here.

Supports NextAuth v4 dir / A256GCMKW. Uses the same HKDF key derivation as NextAuth.
